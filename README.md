# Jendral Import

**Jendral Import** is a web application built on top of the Laravel framework, serving as a comprehensive company profile website for an import services company. The platform provides detailed information about the company’s services, pricing, tracking, and contact features, aiming to enhance the user experience for clients seeking import-related services.

## Project Overview

**Jendral Import** aims to deliver a user-friendly interface for clients looking to:
- Understand the range of services offered by the company.
- Get pricing estimates for different shipping methods (e.g., regular air, express air, sea).
- Track their import orders.
- Reach out to the company for inquiries or support.

The project is built using the Laravel framework, utilizing the MVC architecture to ensure maintainability, flexibility, and scalability.

## Features

The web application includes the following features:

1. **Company Profile Pages**: Displays information about the company, including services, history, and vision.
2. **Dynamic Pricing Calculation**: Allows users to estimate the costs of different shipping options.
3. **Item Order Management**: Users can add, edit, or delete items in their order list.
4. **Shipment Tracking**: Allows users to track the status of their shipments.
5. **Contact Form**: Enables users to send inquiries directly through the website.
6. **Modal Confirmation**: Confirms critical actions such as switching shipping methods or deleting items.
